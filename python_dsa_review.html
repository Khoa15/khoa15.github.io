Cách học: đọc tư duy → tự giải bài trên giấy/IDE 10–20 phút → mới mở đáp án.
Quy trình giải bài khi thi (5 bước): (1) đọc kỹ ràng buộc n để đoán độ phức tạp cần đạt: n ≤ 20 → brute-force/backtracking, n ≤ 10³ → O(n²), n ≤ 10⁵ → O(n log n) hoặc O(n); (2) thử ví dụ nhỏ bằng tay; (3) nhận dạng mẫu bài; (4) viết giải pháp đơn giản trước, tối ưu sau; (5) test các trường hợp biên: mảng rỗng, 1 phần tử, trùng lặp, số âm, tất cả bằng nhau.
